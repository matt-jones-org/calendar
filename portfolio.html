The ballpark

About the site

matt-jones.org is a personal home base — a portfolio that wears its obsessions on its sleeve. The whole site is built around a single running metaphor: a baseball scorecard. Type is set in condensed, all-caps display faces; section labels read like stat-sheet columns in monospace; and a dashed red rule — the stitch of a baseball's lacing — is threaded through every divider, card, and menu.

Underneath the theme it's a fast, hand-built static site: no framework, one clean stylesheet, and a design language that holds together from the hero down to the footer. It splits into two dugouts — Software and Baseball — and invites you to book a time whenever you'd like to talk shop.

Features

Design language

The scorecard look

Baseball stitching, condensed caps, monospace stat-labels, and an outfield-green and lacing-red palette carried across every page.

Light & dark

Day game or night game

Colors respond automatically to the reader's system theme, with a hand-tuned palette for both light "paper" and dark "under the lights" modes.

Booking

Real calendar booking

The Calendar page integrates with Google Calendar to book a slot directly and spin up a Google Meet link for the call — not just a mailto draft.

Navigation

Two dugouts

A sticky top bar with Software and Baseball drop-downs — plus Portfolio and the Calendar — so the whole roster is a hover away from anywhere on the site.

Craft

Accessible & responsive

Focus rings, ARIA labelling, tabular numerals, and a layout that reflows cleanly from a wide desktop down to a phone.

Motion

Reveal on scroll

Sections ease in as they enter the viewport — and quietly turn themselves off for readers who prefer reduced motion.

Up close

Feature spotlights

Two projects with published source, profiled in a little more detail.

LLMAdness

Software · TypeScript

Put the language models in a bracket. One prompt fans out to every model you've configured — Anthropic (Claude), OpenAI (GPT), Google (Gemini), Mistral, and Cohere — so their answers can be lined up and judged head-to-head.

The design leans on doing the unglamorous parts well: a single typed configuration module loads each provider's key from the environment, treats blank values as "not configured," and fails loudly with a helpful message the moment a key is actually needed. Keys live in a git-ignored .env, never in the code, and a config:check script prints exactly which providers are ready to go. Bring only the keys you have; it skips the rest.

TypeScript Node · ESM 5 providers Key-safe config dotenv

Calendar

API Integration · Google

The site's scheduling page — a full Google Calendar integration rather than a plain email draft. Pick a day and a time window on a weekday-only grid ("the weekend is for baseball"), and the booking is written straight to the calendar, with a Google Meet link generated for the call.

Under the hood it authenticates through Google's OAuth flow and talks to the Calendar API, with credentials kept in environment variables rather than in the page. The front end carries the same scorecard design language — accessible by keyboard, reduced-motion aware, and at home in both day and night themes.

Google Calendar API OAuth 2.0 Google Meet Accessible Light / dark

The box score

Summary of work

Across the roster, the through-line is a builder who likes small, sharp tools and cares about how they feel to use. The software dugout runs from language-model work — LLMAdness, which lines up Claude, GPT, Gemini, Mistral, and Cohere on a single prompt — through Cry Wolf, Box Score, Bullzen, and Windhover. The Calendar ties it back to real infrastructure: a Google Calendar and Google Meet integration wired up through OAuth.

The baseball dugout — Magic Number, Black Ink, and Scouting Report — turns the same instinct on the game itself. Tying everything together is the site: a from-scratch static build with a coherent visual system, real interactivity, accessibility baked in, and not a stray pixel out of place.
