The ballpark

About the site

matt-jones.org is a personal home base — a portfolio that wears its obsessions on its sleeve. The whole site is built around a single running metaphor: a baseball scorecard. Type is set in condensed, all-caps display faces; section labels read like stat-sheet columns in monospace; and a dashed red rule — the stitch of a baseball's lacing — is threaded through every divider, card, and menu.

Underneath the theme it's a fast, hand-built static site: no framework, one clean stylesheet, and a design language that holds together from the hero down to the footer. It splits into two dugouts — Software and Baseball — and invites you to book a time whenever you'd like to talk shop.

Craft

Motion

Sections ease in as they enter the viewport — and quietly turn themselves off for readers who prefer reduced motion.

Up close

Feature spotlights

Two projects with published source, profiled in a little more detail.

AICompared

Software · TypeScript

A tool for comparing responses across AI providers. One prompt fans out to every model you've configured — Anthropic (Claude), OpenAI (GPT), Google (Gemini), Mistral, and Cohere — so their answers can be read side by side.

The design leans on doing the unglamorous parts well: a single typed configuration module loads each provider's key from the environment, treats blank values as "not configured," and fails loudly with a helpful message the moment a key is actually needed. Keys live in a git-ignored .env, never in the code, and a config:check script prints exactly which providers are ready to go. Bring only the keys you have; it skips the rest.

TypeScript Node · ESM 5 providers Key-safe config dotenv

Book a Time

Baseball · Vanilla JS

The site's scheduling page, and a neat demonstration of the whole design language in one interaction. A weekday-only month grid — "the weekend is for baseball" — lets you pick a day and a time window (Morning, Afternoon, or Evening, all Central).

There's no backend and no third-party widget: a small hand-written script builds the calendar, limits the view to the next couple of months, and composes a ready-to-send mailto: link with the subject and body already filled in. Cold email works too — calendars optional. It's accessible by keyboard, respects reduced-motion, and looks right in both day and night themes.

Vanilla JS No dependencies Accessible mailto flow Light / dark

The box score

Summary of work

Across the roster, the through-line is a builder who likes small, sharp tools and cares about how they feel to use. On the software side that shows up as work around language models — comparing them (AICompared), bracketing them (LLMAdness) — and around monitoring and the discipline of a good alert (Cry Wolf, Windhover, The Bullzen).

On the baseball side the same instinct points at the game itself: tracking a pennant race (Magic Number), measuring greatness (Black Ink), and keeping a scout's book (Scouting Report). Tying it together is the site itself — a from-scratch static build with a coherent visual system, real interactivity, accessibility baked in, and not a stray pixel out of place.
